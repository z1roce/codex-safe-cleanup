# 调研与取舍（2026-11-02）

本次复用现有 codex-safe-cleanup 的项目元数据盘点、精确文件回收站与恢复能力，不另建项目，不安装新的清理器。先前只查 .codex 缓存的规则漏掉了项目开发产物；现改为所有已关联 Codex 项目和历史输出目录，仍不扫描全盘。项目关联、名称线索与是否废弃严格区分；只有来源核实的精确文件才可进入用户确认清单。

- [WinDirStat](https://github.com/windirstat/windirstat)：官方便携版有有效签名，实际只读统计过三组 Codex 隔离目录，26,333 文件约 1.25 秒。但它是通用磁盘分析工具，不能判断 Codex 数据是否废弃，超出当前小功能所需，因此不作为依赖或主入口。此前下载的便携版和测试材料没有被擅自删除，也不打进技能包。
- [Merlin-Arthur05/codex-clean](https://github.com/Merlin-Arthur05/codex-clean)：实际阅读 README、包元数据和 scripts/codex_clean.py。MIT、标准库 Python，支持 Codex 定向扫描，范围比磁盘工具更贴切。但清理白名单包括 plugins/cache、tmp 和 .tmp，代码直接 unlink/rmdir；另有 SQLite checkpoint/VACUUM。它的 safe/reclaimable 标签不能代替本用户的保留判断。没有安装或执行，不能据此声称做过完整安全审计；不直接使用其 clean。
- [hapwi/codex-cleaner](https://github.com/hapwi/codex-cleaner)：实际阅读仓库说明，侧重本地状态、聊天归档、日志和工作副本；涉及历史/状态及较宽的管理流程，不作为本次简化方案。
- [Codex 官方工作副本](https://learn.chatgpt.com/docs/environments/git-worktrees)：只适用于应用管理的 Git 工作副本。当前需求保护正常项目和历史，本工具不自行归档聊天或删除副本。

元数据统计复用 Python 标准库 os.scandir 返回的属性，不再重复读取每个文件的内容。项目生成物识别会限量只读核对生成脚本、字节码头和 ZIP 中技能身份；不执行项目代码。只有用户所选文件在清理预览阶段计算内容哈希，不做全盘内容扫描。插件、配置、历史、正常项目和未知内容都不因扫描提速而降低保护。

技能和面板不是常驻后台清理器。默认手动启动；不建计划任务、不接 hooks、不修改全局指令。公开版仅发布经核对的代码、说明与合成测试，不包含开发者的个人索引、真实报告、旧包或恢复记录。现有代码为本项目原有实现的复用；候选第三方清理器未作为依赖引入。
