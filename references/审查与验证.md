## 支持范围与保留事项

- 本次实际执行环境为 Windows x64、本地 C/D NTFS 卷。Python3.12与3.14运行通过，其他 Windows 机器、ARM64、macOS、Linux及其他文件系统需要额外验证。
- 继续要求精确文件预览、每批明确确认及同步影响确认。源码、原件、最终成果、Git已跟踪或未知状态、链接、云端占位及未知文件继续保护。手动登记项目不能直接授权删除。
- pytest 识别限于已核对的默认缓存格式，不展开任意插件缓存或自定义 cache_dir。Java规则只覆盖标准布局及已知文件头。字节码识别验证来源位置与头格式，不执行或全面验证编译产物正文。
- 状态目录与原卷暂存区共同参与恢复。卷离线、原生记录不可访问、回收站清空、内容被修改或记录丢失时可能需要人工核对。回收站元数据查找有1万项预算，其他账户的回收站不自动访问。
- 升级备份和中断的安装暂存副本供回退与核对，安装器保留这些目录。用户修改的分发文件需要人工合并后再升级。

## 格式来源与复用取舍

复用原项目的文件身份与哈希、写入锁、NativeLease、Windows Shell 桥接、保留策略和精确确认流程。新增能力使用 Python 标准库、PowerShell 和 Windows 本机接口，运行时依赖成本维持为现有环境。没有引入新的第三方运行时组件。

- pytest规则核对了8.3.5版官方缓存实现和Context7版本文档，包含默认路径、自动生成标记及 nodeids/lastfailed 的JSON结构。项目采用MIT许可，本次只读取格式资料，没有安装pytest或复制其实现。[pytest缓存源码](https://github.com/pytest-dev/pytest/blob/8.3.5/src/_pytest/cacheprovider.py)
- CPython3.12魔数同时由本机运行库核对，3.13与3.14核对官方源码，3.14再以真实编译器验证。[CPython3.13](https://github.com/python/cpython/blob/3.13/Lib/importlib/_bootstrap_external.py) · [CPython3.14](https://github.com/python/cpython/blob/3.14/Include/internal/pycore_magic_number.h)
- Java8至25对应的class主版本52至69由OpenJDK25源码核对，Java21本机编译验证。Java编译器仅为可选开发测试工具。[OpenJDK文件格式版本](https://github.com/openjdk/jdk/blob/jdk-25-ga/src/java.base/share/classes/java/lang/reflect/ClassFileFormatVersion.java)
