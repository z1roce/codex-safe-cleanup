# 使用说明

适用于 Windows，Python 3.12+，无第三方 Python 依赖、无联网、无上传、无需管理员权限。默认仅扫描和建议，不启动任何自动清理。

## 打开和使用

双击 scripts/open-scan-panel.cmd；安装为 Skill 后，也可在 Codex 中说“使用 $codex-safe-cleanup，打开专用检查面板”。

其他电脑：把安装包中的 codex-safe-cleanup 文件夹复制到 `%USERPROFILE%\.agents\skills`，不要覆盖已有同名技能。也可在已允许运行脚本的 PowerShell 中执行 scripts/install.ps1；不需要修改系统执行策略。安装不启用清理。

双击技能中的 scripts/open-scan-panel.cmd 启动。启动器优先使用 Codex 自带 Python，然后查找本机 Python；可以设置环境变量 CODEX_CLEANUP_PYTHON 为 Python 3.12+ 的完整路径。第一次只创建本工具的空配置，已有配置和恢复资料不覆盖。

面板初次不扫描，点击“快速检查 Codex”才生成新报告。重新打开会显示上次符合当前范围的报告，不加载旧版的全盘/历史项目盘点报告。每次扫描都有独立时间和报告编号。加载报告时同时核对项目关联索引和登记记录签名，拒绝关联丢失或版本不符的报告。窗口宽度自动布局，恢复确认窗的按钮固定在可视区域；清单在中间滚动，支持 Esc 取消。

## 范围和速度

范围是所有已关联的 Codex 项目及任务产物：登记项目、历史聊天工作目录、Codex 任务输出目录，以及 .codex/明确 CODEX_HOME 的运行数据。项目关联索引保存原始标题、任务ID、路径和捕获时间，聊天正文不保存。桌面扫描从已保存索引和 Codex 本机项目路径字段补充范围，不扫描整个 C 盘、桌面、文档或无关软件。通用用户根被拒绝；找不到的项目路径明确列出。网页不能通过任意路径参数扩展范围。

只有 cache、tmp、.tmp 做文件名和大小统计，不读取文件内容、不算哈希、不判断重复。插件子目录和插件索引不深入。根目录文件只取大小，不打开配置、凭据或 SQLite。

配置、指令、Skills、插件、历史和备份继续保护。正常项目、任务输出及工作副本可以只读盘点名称与大小；源码、原件、成果和未知文件不因项目关联而获清理许可。版本历史、密钥、链接和云端内容跳过。未统计的大小显示“未统计”，不是0。

运行数据最多2万文件/10秒；项目盘点最多20万文件/30秒；不可读、保护跳过、链接和云端占位会说明。小范围元数据统计通常较快，但不保证任何磁盘、规模或网络状态都能秒完成。

报告只表示已统计文件的逻辑大小，不代表整个 .codex 的占用，也不是可释放空间。待核对不等于确认可清理；缓存名、位置、大小和日期不构成删除证据。当前 CODEX_THREAD_ID 对应的应用清单不纳入；无法自动完整判断所有活动任务，用户仍需确认不再使用或引用。

## 清理与恢复

面板提供“全选待核对项”、Ctrl+Alt+A、“取消全选”和“一键清理到回收站”。只选择已识别来源的具体缓存文件；不会选中插件、配置、历史、项目或未知文件。点击清理后先核对清单，再勾选“已不再需要、不再引用”并确认，才移入 Windows 回收站。初次确认框不会自动勾选。同时支持逐文件登记或自动核实生成证据的 Codex 项目产物，例如已结束阶段的测试输出、性能报告和旧交付包。项目线索不等于废弃证明，未知文件不加入全选；旧包仍可能用于回滚。需要处理时，在聊天中指定条目，请 Codex 核实来源、用途、引用和保留价值；确认精确文件清单之后才进行可恢复处理。配置、插件、历史和正常项目不能通过确认框强制绕过保护。安装或要求完善此工具不构成实际清理许可。

项目识别会限量只读核对 Python 字节码头、生成测试日志的代码和打包排除规则、同技能历史 ZIP 身份，不执行项目代码。已识别和受保护文件都显示在建议中；旧包可能有回滚价值，日志可能用于诊断，依赖缓存可能还需构建使用，不能自动判为无用。Git 已跟踪或状态未知的内容不清理。已核实生成且未跟踪的同步文件可预览，需额外勾选云端/其他设备同步移除确认，默认不勾选。

旧隔离资料保留，面板“旧版隔离与恢复记录”可查看。点击“查看恢复清单”，核对原路径并勾选确认后恢复；目标已有内容则停止，不覆盖。本版不再提供旧项目再次回收或压缩按钮，避免沿用旧范围授权。

本次缓存清理记录也显示于恢复记录，支持恢复到原位置，不覆盖同名文件。安全校验先同卷暂存，后调用原生回收站；Windows 直接右键还原可能先回到暂存位置，请优先用面板恢复。每批最多100文件、128MiB，单文件128MiB；仅所选文件做哈希，日常运行数据检查只读元数据；项目生成物另做限量格式和生成证据核对。

回收站仍占磁盘空间，也可能被 Windows 或用户清空；清空后可能无法恢复。本工具不会清空回收站。隔离记录与 ZIP 应保留；旧精确文件 ZIP 隔离仍可使用 scripts/run-cleanup.cmd history 和 restore --batch <编号>。

## 关闭与记录

点击“关闭面板”停止服务，或以后不调用技能。默认没有开机启动、后台扫描或定时清理；空闲 30 分钟退出。关闭或重启后旧 localhost 链接可能失效，重新双击启动入口获取新地址。

项目范围和任务产物在面板中单独展示，标明索引时间、覆盖/缺失路径、来源及继续保留原因。artifact-registry.json 是精确文件的来源登记，不是删除授权，也不会直接清理整个目录。

记录在 `%LOCALAPPDATA%\CodexSafeCleanup`，新报告位于 codex-reports。旧 inventory-reports、reports 和隔离记录不会删除，也不会当成本轮扫描结果。

命令行可运行 Python 加本技能 scripts/inventory.py；--scopes 只显示范围。扫描命令可以独立使用，不需安装其他磁盘软件。
